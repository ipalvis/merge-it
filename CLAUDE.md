# Merge It! — notes for Claude Code

Browser game: drop the pieces of a map (U.S. states or European countries) into a box; pieces that border each other on the real map stick together. Goal is to assemble the whole map. Plain JavaScript (ES modules), Matter.js physics, Web Audio, bundled with Vite. See README.md for the full project structure.

## Commands

- `npm run dev` — dev server at http://localhost:5173 (hot reload). `?test=1` deals only Colorado + Utah for quick win/Endless checks. `?map=eu` loads the Europe map (Spain + Portugal with `?test=1`); without `?map=` the game opens on the last map played. Check changes on both maps.
- `npm run build` — production build to `dist/` (what Cloudflare Pages serves). Run this before saying a change is done.
- `npm run format` / `npm run format:check` — Prettier. Run `format` after editing.
- `npm run build:single` / `npm run build:single-test` — single-file builds for claude.ai artifacts.

## Deploying

Every push to `main` on GitHub auto-deploys to Cloudflare Pages (https://merge-everything.pages.dev; the Pages project and GitHub repo still use the game's former name). Do not push to `main` unless asked. For risky changes, use a branch (Cloudflare builds a preview URL per branch).

## How the code is organized

- Shared mutable state lives on `G` in `src/state.js`. Values only one module uses stay private to that module.
- Gameplay tunables live in `CFG` in `src/config.js` (gravity, red line, cooldowns, blends per round, scoring). Prefer adding a CFG value over a magic number.
- Flow is driven by `G.state`: `title | playing | blending | bankpick | banking | clearing | won | over | tutorial`. Physics only steps in `playing`, `clearing`, `blending`.
- Physics bodies for pieces are Matter compound bodies ("groups") with `g.ids` (a Set of state ids). The waiting piece is `G.current`, a piece object with `.states` (array), `.name`, `.R`, `.c`.
- Merges: `src/physics/world.js` queues neighbor contacts and snaps merged pieces into true map position; `onMerged` in `src/game/game.js` handles scoring, toasts and round completion.
- Tutorial: `src/game/tutorial.js`. While it runs, `G.tut` holds allowed actions and hooks (`dropped`, `merged`, `shaken`, `banked`, `blendStart`, `blendDone`, `tick`). Gameplay code calls `G.tut?.hook?.()` and checks `tutBlocks(action)`. Any new player action should respect `tutBlocks`.
- Rendering is all canvas in `src/render/render.js`; colors come from CSS variables via `theme` (`src/ui/theme.js`), so both light and dark themes work. Use theme colors, not hard-coded hex, in canvas drawing.
- Sounds are synthesized in `src/audio/sound.js` (`Sound.fx.*`); there are no audio files.
- Levels (maps): `src/map/level.js` picks `MAP` (`us.js` or `eu.js`) from the URL or the last one played; the U.S. | Europe switch in the top bar reloads with `?map=` set. Per-level content (colors, clusters, bonus divisions/regions, wording, test ids) lives there, not in shared code. In code, a "state" is any map region (a U.S. state or a country); user-facing text uses `MAP.unit`/`MAP.units`. The tutorial is U.S.-only (`MAP.tutorial`). A level can narrow the box (`MAP.boxW`; Europe uses 371), which sets `CFG.boxW`/`VW`; it's drawn at the scale a standard box would get (`VW_STD`), so pieces look the same size. Every map gets fitted labels (`src/map/labels.js`) and the finished-map preview panel toggled by the ? button (`src/game/preview.js`; drawn in `updateHUD`). Keep gameplay and wording the same across maps; per-map differences belong in the map files (song, box width, tutorial, sea crossings).
- Map data in `src/data/` (`states.json`, `eu.json`) is generated by `scripts/build-map.mjs`; don't hand-edit it.

## Conventions

- Matter.js is pinned at 0.19.0 on purpose. Don't upgrade it.
- Keep changes small and in the existing style (short comments explaining why, Prettier formatting).
- Saved data uses `localStorage` keys in `STORAGE_KEYS` (`src/config.js`); always wrap localStorage in try/catch.
- Check layouts at desktop width (bank and reset sit beside the box) and phone width (~390px, bank sits in the header).
